Para resolver esse desafio sem estourar o limite do localStorage (que costuma ter um teto de 5MB por domínio) e ao mesmo tempo garantir que você consiga baixar o arquivo com a qualidade original, criei uma solução inteligente de compactação via JavaScript (pako / gzip) integrada diretamente ao módulo de Documentos. Como funciona: * Compactação Automática: Ao selecionar o PDF (ou imagem), o sistema utiliza compressão GZIP no navegador antes de salvá-lo. Isso reduz drasticamente o tamanho do arquivo (muitas vezes em mais de 70%), fazendo com que ele ocupe pouquíssimo espaço no banco de dados local. * Descompactação Transparente para Download: Quando você clica em baixar ou visualizar o documento, o sistema reconstrói o arquivo com exatamente 100% da qualidade original com que foi enviado. * Biblioteca nativa incluída: Adicionei via CDN a biblioteca de compactação pako, sem precisar instalar nada externo.
